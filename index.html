Sports Hall Booking System

Project Overview

A ServiceNow-based Sports Hall Booking System for managing sports hall bookings, time slots and booking requests.

Technologies Used

  • ServiceNow
  • App Engine Studio
  • Service Catalog
  • Flow Designer

Project Features

  • Sports Hall Management
  • Time Slot Management
  • Sports Hall Booking
  • Automated Booking Flow
  • Booking Status
